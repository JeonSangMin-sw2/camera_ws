# Step1 브래킷/J6 수정과 검증 — 2026-09-09

## 범위와 원칙

이번 변경은 브래킷의 J6 동축 회전 1자유도 고정, 브래킷→J6 순서,
보정 후 재검증, Median 선택, 시야 이탈 후 재취득 경로에 한정한다.
새 core 파일은 만들지 않는다. J3/J5 계산식과 Step1.5/Step2 최적화식은
이번 변경에서 수정하지 않는다. 따라서 **Step1 전체를 09/02 코드로 되돌린 것은 아니다.**

실물/시뮬 구분을 계산·수렴 판정에 추가하지 않는다. 기존의 마커 공급 방식과
전원 선택만 다르게 유지하며, 시뮬 정답을 보정기에 전달하지 않는다.

## 구현 순서

1. 실패하는 회귀 테스트로 기존 문제를 재현한다.
2. 브래킷의 회전을 CAD 대비 J6 축 twist와 나머지 swing으로 분리한다.
   twist는 0으로 고정하고 swing 2자유도와 위치 3성분을 구한다.
   손목 교점 기준으로 위치도 함께 변환한다. Euler 각 하나를 덮어쓰지 않는다.
   손목 교점 위치는 모든 관측에 `p_camera + R_camera_marker × pivot_marker =
   pivot_camera`를 함께 맞춰 추정한다. 기존 원/축 교점 품질 검사도 유지한다.
   시간창 Median이 아닌 공간상의 강건 최소제곱이며, SDK 관절값을 쓰지 않는다.
3. J5 → 브래킷 → J6 → 브래킷 새 관측 검증 → J3로 실행한다.
   J6는 최신 브래킷 값을 우선 사용한다. 버전별 저장값은 최신 값이 없을 때만 사용한다.
4. 과거 J6 5프레임 이동 Median은 단일 상수로 선택한다.
5. 티칭 전후의 스윕을 섞지 않고 승인된 J5 보정을 유지한다.
6. 오프라인 전체 회귀 테스트와 v1.2 연결 시뮬레이션을 수행한다.

## Pass 1 / Pass 2의 의미

기존 현재 코드의 Pass 2는 실패한 관절만 재시도하며, 성공한 브래킷/J6를
새 관측으로 재검증하지 않았다. 전체 반복을 제거한다고 재검증까지 없어져서는 안 된다.

이번에는 다음처럼 분리한다.

- 각 관절의 반복 수렴 확인은 유지한다.
- 최대 2회 외부 Pass는 실패한 관절의 재시도 용도로 유지한다.
- J6 수렴 후 브래킷의 J4/J6/J5 스윕을 새로 수집한다.
- 고정된 좌표 기준에서 앞선 브래킷과 위치 차이 ≤0.5 mm, 회전 차이 ≤0.5°인지 검사한다.
- 고정 과정에서 분리된 잔여 J6 동축각도 유한한 값이며 절댓값 ≤0.5°인지 검사한다.
  고정된 브래킷끼리만 비교하면 이 성분이 사라져, J6의 다른 추정 편향을 놓칠 수 있다.
  이 기준은 서로 다른 관측 계산의 일관성 검사이며, J6 자체의 반복 수렴 기준 0.06°와 구분한다.
- 검증 결과로 브래킷이나 J6를 다시 변경하지 않는다. 불일치는 실패 처리한다.
- 이는 반복 관측의 일관성 검사이지, 실물의 절대 정확도를 증명하는 검사는 아니다.

동축 자유도는 관측만으로 물리적으로 분리할 수 없다. CAD/조립 기준으로 선택한
브래킷과 그 기준에 따른 **유효 J6 오프셋**을 얻는다. 실제 조립의 동축 오차가
존재하면 그 성분은 J6 값에 포함된다.

CAD 기준은 `config/ready_poses.yaml`의 `calibration.nominal_brackets`를 사용한다.
`setting.yaml`의 지난 보정 결과를 CAD 기준으로 다시 정의하지 않는다.

## Median 실물 A/B 시험

`core/calibration/legacy_j6.py`의 `USE_J6_INITIAL_MEDIAN` 하나로 선택한다.

- `False` (현재): 5프레임 이동 Median 생략.
- `True`: 과거 초기 원 피팅의 5프레임 Median 복원.

기하 잔차 기반 강건 피팅과 품질 검사는 유지한다. 이 Median은 최종 원 피팅의
초기 추정에 쓰이던 것으로, 모든 최종 관측값을 시간 보간하는 기능은 아니다.
카메라/엔코더 timestamp 동기화는 이번에 추가하지 않았다. SDK 엔코더와
FK 축 초기 방향을 사용하는 기존 v1.2 J6 알고리즘 자체도 이번에 제거하지 않았다.

## 재취득 수정

- J6/브래킷 티칭 시 J5를 명목각만으로 덮어쓰던 경로를 수정한다.
- 티칭 자세는 보정이 포함된 SDK 명령값으로 저장하고, 이동 시 다시 더하지 않는다.
- 브래킷에서 시야 이탈로 티칭하면 이전에 수집한 모든 축을 버리고 새 자세에서 재수집한다.
- 디버그 TXT도 세 축의 수집이 모두 끝난 후 기록해, 버린 자세의 일부 축만 남지 않게 한다.
- UI에 티칭을 요청한 보정 종류를 전달해 이전 관절 모드가 브래킷 요청에 섞이지 않게 한다.
- 티칭 자세 저장 실패를 성공으로 처리하지 않는다.

## 검증 기록

- 오프라인 전체 검사: 180개 실행, 178개 통과, 선택 실행 2개 건너뜀, 실패/오류 0.
- 첫 연결 시험: J5 첫 스윕 도중 서버 `head_1` 상태 갱신 timeout(200 ms),
  `MajorFault`로 중단. J6/브래킷 계산까지 도달하지 못한 실행이다.
- 두 번째 연결 시험: 오른팔 J5와 J6 수렴. J6 = −2.3530°, 마지막 잔여 보정량
  −0.0069°. 이후 브래킷 재검증 위치 차이 0.5639 mm로 실패 처리했다.
- 동일 원시 관측 재생에서 짧은 원호 중심의 오차가 교점 위치에 반영됨을 확인했다.
  전체 관측 공통 교점 피팅 적용 후 차이 0.2384 mm, 각 캡처의 교점 잔차
  0.1726 / 0.1768 mm. 검증 기준 0.5 mm는 변경하지 않았다.
- 최종 연결 시험: **Step1 → Step1.5 → Step2 전체 정상 종료, exit 0**.
  BLAS/OMP 스레드 수 1, 기본 스윕 시간 유지, 설정·결과는 임시 사본 사용.
- Step1: 양팔 모두 외부 Pass 1에서 완료. 별도의 전체 Pass 2 재실행은 없었다.
- Step1.5: 잔차 0.2338 mm, rank 9/9로 저장·적용 완료.
- Step2: 64/64 자세 수집, 최적화 19회 반복 후 수렴. 위치 잔차 0.02525 mm,
  회전 잔차 0.002223°. 원본 설정 해시 보존 검사 통과.

| Step1 결과 | 오른팔 | 왼팔 |
|---|---:|---:|
| J5 명령 보정값 | −5.4024° | +3.0052° |
| J6 명령 보정값 | −2.4089° | −3.5025° |
| J3 명령 보정값 | −0.5028° | −0.7033° |
| 브래킷 재관측 위치 차이 | 0.2992 mm | 0.1533 mm |

오른팔 J6는 이전 실행 −2.3530°와 이번 실행 −2.4089° 사이 약 0.056° 차이가 있었다.
실물 반복성을 확정하는 결과가 아니며, 실물 Median A/B 시험은 여전히 필요하다.

### 연결 시험 후 마무리 변경의 검증 범위

연결 시험 종료 후 `calibration_core.py`에 잔여 동축각 검사와 디버그 일괄 기록을
추가했다. 로봇 모션·보정 계산식은 이 마무리 변경에서 바꾸지 않았다.
이후 전체 SDK 모션을 재실행한 것은 아니다. 최종 코드의 실제 FullAuto 검증
경로와 MarkerCalibrator에 양팔의 저장된 브래킷 관측을 재생해 세 검증 항목이
모두 통과하는 것을 확인했다. 관절 추정 자체는 다시 돌리지 않고 성공한 연결
시험의 승인 결과를 사용했다. 실패 동축각/NaN/재취득 기록의 회귀 테스트도 통과했다.
최종 오프라인 전체 결과는 180개 중 178개 통과, 선택 항목 2개 건너뜀이다.

연결 대상: `127.0.0.1:50051`, SDK `M@v1.2`.
결과·설정 사본·실행 로그: `/tmp/camera-j6-cad-check.30zCcK/`.
원본 설정 파일과 로봇 홈 오프셋은 변경하지 않는다.

읽기 전용 코드 리뷰에서 확인한 동축각 검증 누락과 부분 디버그 기록 문제를
보완했고, 해당 마무리 변경의 재리뷰에서도 추가 문제는 발견되지 않았다.

증거 파일:

- `final/summary.json`: 연결 시험 결과, 당시 소스 해시와 원본 설정 보존 여부.
- `final.log`: 전체 SDK 실행 로그.
- `post-review-replay.json`: 최종 코드로 관측 재생한 추가 검증 결과 및 변경 파일 해시.
- `unit-reviewed.log`: 최종 전체 오프라인 테스트 결과.

Step1.5의 시간창 평균/필터와 Step2의 파라미터 고정 정책은 이 변경의 검증과
구분해야 한다. 특히 현재 Step2 실행이 종료됐다는 사실만으로
“J0/J1/J2/J4만 추정한다”는 요구까지 충족됐다고 판정하지 않는다.
실제로 이번 Step2 결과의 자유변수는 **21개**였다. 이 항목은 원래의 8개 관절
보정 목표와 다르며, 이번 브래킷/J6 변경으로 해결됐다고 보고할 수 없다.

## 실물에서 남은 확인

1. CAD/조립 기준이 실제 브래킷 장착 기준과 일치하는지 확인한다.
2. 동일 준비 자세에서 Median OFF/ON 각각 반복하고 J6 값의 분산,
   브래킷 재관측 차이, 마커 회전 추정의 튐을 비교한다.
3. 시야 이탈 후 티칭에서 승인된 J5가 유지되는지, 새 자세의 모든 축을
   다시 모으는지 확인한다. 이전 스윕과 새 스윕이 섞이면 승인하지 않는다.
4. 시뮬 통과만으로 실물 PnP 오차·조명·영상 지연까지 해결됐다고 보지 않는다.
