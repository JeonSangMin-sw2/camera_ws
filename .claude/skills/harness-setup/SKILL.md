# 프로젝트에 하네스 적용
1. 프로젝트 `CLAUDE.md`에 행동 지침, 절대 규칙, 구조 문서(`rules/architecture.md`) 링크를 쓴다. 🔴 규칙, 날짜가 붙은 안티패턴, 래칫 기록은 이 프로젝트의 규칙 절에 쓴다. 게이트별 명령은 프로젝트 harness에 둔다.
2. `.claude/settings.json`에 DENY·ASK를 권한 규칙으로 넣고, 조건이 필요한 것은 `.claude/hooks/`에 hook으로 둔다. 하드웨어를 움직이는 스크립트 목록은 프로젝트마다 조사해서 넣는다.
3. 구조 경계(`rules/architecture.md`의 의존 방향)를 테스트로 만든다. 현재 통과하는 규칙만 넣고, 기존 위반은 보고만 한다.
4. `docs/progress.md`를 만들어 재개 지점과 작업 항목을 기록한다.
- 규칙은 **검증 가능하게** 쓴다. "잘 짜라", "최대한 통일" 같은 표현 대신 "두 모듈 이상에서 쓰는 상수는 config에만 정의한다"처럼 테스트나 grep으로 확인할 수 있게 쓴다.
