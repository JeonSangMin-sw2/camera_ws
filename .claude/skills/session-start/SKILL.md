# 세션 시작 체크리스트
새 세션이나 새 작업을 시작할 때 AI가 가장 먼저 하는 일입니다.
1. **문서를 이 순서로 읽는다**: 공통 하네스(`CLAUDE.md`와 `.claude/rules/`) → 프로젝트 harness → 아카이브 process(특히 '재개 지점'과 진행 기록 최신 2건) → 작업과 관련된 detail 요구사항·기능. `[rby1]`
2. **트랩 분류를 먼저 확인한다**: 🔴 ACTIVE는 반드시 준수, ✅ RESOLVED는 과거 이력일 뿐 다시 적용하지 않음. 감내할 한계로 정하는 경우에는 허용 오차 같은 통과 기준을 먼저 정의하고, 그 기준으로 처리한다. `[cam]`
3. **저장소 상태를 확인한다**: 작업 디렉터리, 브랜치, 마지막 커밋, 미커밋 변경 목록.
4. **규칙 충돌을 확인한다**: 로컬 규칙(CLAUDE.md, AGENTS.md, 에이전트 메모리)과 노션 규칙이 다르면 작업 전에 사용자에게 확인한다.
5. **문서의 버전·경로를 맹신하지 않는다**: 문서의 버전 표기와 실제 설치 버전, 문서의 모듈 경로와 실제 코드를 대조한다. 다르면 사용자에게 알린다. `[cam]`
