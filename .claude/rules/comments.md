# 주석 규칙

주석은 코드가 말해 주지 않는 것만 쓴다. 한 줄, 길어도 두 줄이고 세 줄은 쓰지 않는다. 문장은 자연스럽고 간결하게 쓴다.

## 쓰지 않는 주석
- 구분선과 대문자 제목 (`# =====`, `# WORKFLOW`)
- 코드를 그대로 되풀이하는 주석 (`count = 0` 위에 `# 변수 초기화`)
- 단계 나레이션 (`# Step 1`, `# 다음으로`)
- 이름만 붙인 빈 라벨 (`# 메인 로직`, `# 헬퍼 함수`, `# 주의: 중요함`)
- 구체적이지 않은 TODO (`# TODO: 개선`). 쓰려면 무엇을 왜 하는지 적는다
- 함수 이름과 인자가 이미 말하는 것을 되풀이하는 docstring
- 장식 이모지
- 끝 표시 (`# end if`)

## 남기는 주석
- 의도와 이유, 설계 결정
- 보안, 성능 trade-off, 동시성 동작
- 프로토콜 세부, API 계약
- 우회 방법과 예외 상황, 라이선스 고지
- 되돌린 시도의 사유 (`coding-principles`의 실패한 시도를 반복하지 않는다)

## 범위
- 내가 쓰는 주석에만 적용한다. 기존 주석은 요청이 없으면 고치지 않는다.
- 주석만 정리할 때도 코드, 식별자, import, 서식, 로직은 건드리지 않는다.
