# UI 규칙 (PySide6)

PySide6 어두운 테마 데스크톱 UI의 색·버튼·글자 규칙이다. 구조와 코드 골격은 지식 카드(PySide6 UI 묶음)에 있다. 색은 `theme.yaml` 토큰 한 곳에서만 정의하고, 위젯에는 역할 속성(`variant`, `scale`, `status`, `tone`, `kind`)만 붙인다. 새 색이 필요하면 `theme.yaml`에 토큰을 추가하고 이 규칙의 표에 적는다. 위젯에 hex를 직접 쓰지 않는다.

## 4. 색상 체계
### 원칙
- 어두운 배경 단계 위에 의미 있는 색만 올린다.
- 같은 역할이면 같은 색. 색 값은 `theme.yaml` 한 곳에만 쓴다.
- 버튼 색은 중요도가 아니라 "무엇을 하는가"로 고른다 (버튼 규칙).
- 밝은 주황(`save`)만 글자를 검정으로 하고, 나머지 버튼 글자는 흰색.
### 배경·테두리·글자

| 토큰 | 값 | 용도 |
|---|---|---|
| `surface.base` | `#121212` | 창 배경, GroupBox 제목 바탕, 로그 바탕 |
| `surface.panel` | `#1a1a1a` | GroupBox, 탭, 상태 바, 카드 |
| `surface.input` | `#1e1e1e` | 입력칸, 콤보, 표, 목록 |
| `surface.raised` | `#2a2a2a` | 선택 탭, 진행바 바탕, 카드 hover |
| `surface.divider` | `#2d2d2d` | 탭·표 격자, 스플리터 손잡이 |
| `surface.border` | `#333333` | GroupBox·카드·상태 바 테두리 |
| `surface.border_strong` | `#444444` | 입력칸 테두리 |
| 표 헤더 / 선택 | `#263238` 바탕, 선택 글자 `#00e5ff` | `QHeaderView`, 표·목록 선택 |
| `text.strong` | `#ffffff` | 버튼 글자, 제목 |
| `text.primary` | `#e0e0e0` | 본문 |
| `text.secondary` | `#b0bec5` | 설명, 표 헤더 |
| `text.muted` | `#9e9e9e` | 힌트, 범위 표시, 대기 상태 |
| `text.disabled` | `#616161` | 비활성 버튼 글자 |

### 강조색 (tone)

| 토큰 | 값 | 용도 |
|---|---|---|
| `tone.value` | `#00e5ff` (시안) | 측정값·수치, SpinBox 값, 선택된 카드 테두리, 표 선택 글자 |
| `tone.section` | `#448aff` (파랑) | 그룹 제목, 안내 박스 제목 |
| `tone.headline` | `#ffd700` (금색) | 앱 이름, 화면 제목, 경고 다이얼로그 제목 |
| `tone.guide` | `#ff5252` (연빨강) | 주의 안내문 ("보드를 흔들지 마세요" 류) |

### 상태 색 (status)

| 상태 | 값 | 언제 |
|---|---|---|
| `idle` | `#9e9e9e` | 대기, 아직 안 함 |
| `running` | `#1e88e5` | 진행 중, 이동 중. 진행바 색도 같음 |
| `success` | `#00e676` | 완료, 감지됨, 활성 |
| `warning` | `#ff9800` | 부분 성공, 취소됨, 사용자 확인 필요, 경고 영역 제목 |
| `error` | `#ff1744` | 실패, 미감지, 비활성 |

- 상태 바는 왼쪽 4px 띠와 글자에 같은 상태 색을 쓴다.
- 상태 표시등(`IndicatorWidget`)도 같은 두 색을 쓴다: 감지 `#00e676`, 미감지 `#ff1744`.
### 자주 쓰는 배색 조합
**기본 화면**
- `#121212` 배경 위에 `#1a1a1a` 패널과 `#e0e0e0` 글자, 버튼만 색을 가진다.
**데이터 강조**
- `#1e1e1e` 입력칸·표 위에 `#00e5ff` 값. 선택 행은 `#263238` 바탕.
**안내 화면 (마법사·빈 화면)**
- `#ffd700` 화면 제목, `#448aff` 그룹 제목, `#dddddd` 굵은 본문, `#ff5252` 주의 문구.
**결정 다이얼로그**
- 초록 확정(`run`, 넓게 stretch 2)과 빨강 취소(`danger`, stretch 1), 둘 다 큰 크기 (camera_ws `main_ui.py:327~338`).
**순서 버튼 열**
- 파랑 이동(`move`) → 초록 실행(`run`) → 주황빨강 반영(`apply`). 맨 위에 빨강 정지(`danger`).

## 5. 버튼 규칙
### 역할별 색 (variant)

| variant | 배경 / hover / pressed | 언제 쓰나 |
|---|---|---|
| `default` | `#2c3e50` / `#34495e` / `#1a252f` | 역할 없는 버튼 (닫기, OK) |
| `move` | `#2b5278` / `#34689a` (제안) / `#1f3d5a` (제안) | 로봇 이동, 연결, 파일 열기, 창·그래프 열기 |
| `primary` | `#1e88e5` / `#2196f3` / `#1565c0` | 다음 단계, 캡처, 빈 화면의 첫 동작, 선택된 토글 |
| `run` | `#43a047` / `#4caf50` / `#388e3c` | 시작, 계산, 완료 확인 |
| `apply` | `#d84315` / `#e64a19` / `#bf360c` | 로봇 홈·설정 파일에 기록 (되돌리기 어려운 반영) |
| `save` | `#fb8c00` / `#ffa726` (제안) / `#ef6c00` (제안), 글자 검정 | 저장, 주의가 필요한 보조 실행 |
| `neutral` | `#546e7a` / `#78909c` / `#37474f` | 이전, 취소, 초기화, 지우기, 처음 화면으로 |
| `danger` | `#e53935` / `#ef5350` / `#d32f2f` | 정지, 작업 취소, 리셋, 되돌리기, 삭제, 종료 |

- (제안) 표시 값은 현재 코드에 없는 신규 hover·pressed 색이다.
- 비활성 버튼은 역할과 관계없이 `#262626` 바탕에 `#616161` 글자.
### 크기 (scale)

| scale | 최소 높이 / 글자 / 모서리 | 쓰는 곳 | 현재 코드 값 |
|---|---|---|---|
| `sm` | 26 px / 11 px / 4 px | 밀집 패널 (조작형 3열, 상단 바, 상태 바) | 24~28 px |
| `md` | 35 px / 12 px / 4 px | 일반 | 노출 APPLY·CANCEL 35 px |
| `lg` | 45 px / 14 px / 6 px | 빈 화면 첫 동작, 마법사 내비게이션, 카메라 탭 조작 | 45 px (140×45 고정) |
| `xl` | 56 px / 16 px / 6 px | 결정 다이얼로그, 상태 토글 | 52~60 px |

### 배치 규칙
**순서**
- 한 GroupBox 안의 버튼은 작업 순서대로 위→아래(또는 왼→오른쪽)로 두고 `1)` `2)` `3)`을 붙인다.
- 정지 버튼은 작업 버튼보다 위에 둔다 (camera_ws `STOP MOTION`, `main_ui.py:1457`).
**활성 조건**
- `apply` 버튼은 반영할 결과가 생기기 전까지 비활성.
- 실행 중에는 작업 버튼을 잠그되 정지·취소 버튼은 항상 활성.
**확인**
- 되돌리기 어려운 동작(`apply`, `danger` 리셋·삭제)은 확인 다이얼로그 뒤에 실행한다.
- 확정·취소 쌍은 확정을 왼쪽·넓게, 취소를 오른쪽에 둔다.
### 버튼이 아닌 역할 속성 (kind)

| kind | 위젯 | 모양 | 쓰는 곳 |
|---|---|---|---|
| `card` | 체크 가능한 `QPushButton` (`make_card`) | 패널 바탕, 두 줄(제목 / 숫자), 선택되면 `tone.value` 테두리 | 분석형 요약 카드 겸 필터 |
| `drawer` | `QToolButton` 화살표 | 테두리 없음, `status.warning` 글자 | 접히는 경고 영역 제목 |

## 9. 따라 하지 말 것

| 하지 말 것 | 왜 | 대신 |
|---|---|---|
| 화면 전체를 파일 하나·클래스 하나에 | 한 곳을 고치면 먼 곳이 깨지고, 읽는 데 오래 걸린다 | 화면 부품·작업 영역별 파일 (PySide6 UI 카드의 구조와 코드 골격) |
| 위젯마다 색을 직접 지정 | 같은 역할이 여러 색으로 갈라진다 | `variant` / `scale` / `status` / `tone` 속성 |
| 버튼 문구에 이모지 | 글꼴·OS마다 모양과 폭이 달라지고 번역 문자열이 지저분해진다 | 문구만. 아이콘이 필요하면 `QIcon` |
| 번역 없이 고정 문구 | 언어 전환 때 일부만 바뀐다 | 모든 화면 문자열을 `tr()`로 |
| 같은 버튼을 두 곳에서 따로 정의 | 한쪽만 고쳐져 동작·모양이 어긋난다 | 부품 함수나 클래스 하나로 만들고 두 곳에서 사용 |
| 장비 호출을 `threading.Thread`로 | rby1_sdk에서 segfault | `QThread` 워커 (코드 골격의 `TaskWorker`) |
| 진행 중 상태를 주황으로 | 경고와 구분되지 않는다 | 진행은 `running`(파랑), 주황은 `warning`만 |

## 10. 새 UI 체크리스트
- [ ] 작업 영역 틀을 골랐다: 조작형(3열) 또는 분석형(카드와 목록·상세). 한 탭에 섞지 않았다
- [ ] 화면 공통 순서를 따른다: 상단 바 → 상태 바 → 빈 화면 또는 탭 → QUIT
- [ ] `theme.yaml`·`ui/theme.py`를 복사하고 `app.setStyleSheet(build_stylesheet(load_tokens()))`를 한 번만 불렀다
- [ ] 위젯에 `setStyleSheet`로 색을 쓰지 않았다 (`variant` / `scale` / `status` / `tone` / `kind`만)
- [ ] 버튼 역할을 버튼 규칙의 역할 표에서 골랐다. `apply` 버튼은 결과가 생기기 전 비활성
- [ ] 긴 작업은 `TaskWorker`에서 하고, 상태 바에 진행률과 취소 버튼이 보인다
- [ ] 취소된 결과를 성공으로 취급하지 않는다
- [ ] 실행 중 잠금 목록에 정지·취소 버튼을 넣지 않았다
- [ ] 되돌리기 어려운 동작 앞에 확인 다이얼로그가 있다
- [ ] 화면 문자열은 모두 `tr()`을 거치고, 버튼 문구에 이모지가 없다
- [ ] 로그는 `log_msg()` 하나로 쓴다 (스레드 안전)
- [ ] `main_ui.py`에는 조립만 있고, 부품·작업 영역은 `ui/` 아래 파일에 있다
